Methodology, including its limits

Honest measurement means saying where the comparison is imperfect. Ours:

  • Real assets. Every image and the ad GIF on the "before" page were downloaded from thedailystar.net's own servers on 25 July 2026. The 6.94 MB GIF is the genuine file, not a stand-in.
  • The 41 stylesheets are emulated. We generated 41 small local CSS files to reproduce the request-chain shape of the live page's 74. Fewer files than the real page, so this understates the real cost.
  • Third-party scripts are emulated, not loaded. Running live Google Ads and Facebook tags in a demo would be both unethical and unreproducible. Instead both pages execute an identical, deterministic ~900 ms of CPU work — less than a quarter of the 3,890 ms Lighthouse measured from real third parties. The before page runs it synchronously (as tags do today); the after page runs the same work in idle slices. The delta is therefore about scheduling, not about deleting analytics.
  • Both pages served identically: same local static server, no compression differences, same Lighthouse flags, same Chromium build, three runs each, medians reported.
  • Why "before" LCP (38.0 s) exceeds the live page's (23.7 s): our section concentrates the lazy lead image and the heaviest GIF in one short document with no other content to paint, so the queue effect is more extreme. Directionally identical, magnitude not directly transferable — which is why the projections on the fix list are pegged to the live audit, not to this demo.
  • Field data is absent. See the note in the diagnosis: the keyless CrUX/PSI quota was exhausted, and we do not publish numbers we did not measure.

Reproduce: serve this folder over any static server and run
npx lighthouse http://localhost:PORT/demo/before/index.html --form-factor=mobile --screenEmulation.mobile --throttling-method=simulate --only-categories=performance
then repeat for /demo/after/index.html.

The transferable lesson

The 100/100 is not the point — a nine-card section will always outscore a full news homepage. The point is that four cheap changes, none of which removed a single feature, accounted for the entire difference. No framework, no replatform, no reduction in advertising or analytics coverage.
